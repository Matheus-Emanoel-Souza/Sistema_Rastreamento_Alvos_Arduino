Apoio para usuário:
Aplicativos para fazer o diagrama de classes.
Manual UML class diagram tools, good pick:

- draw.io / diagrams.net — free, offline-capable, UML shapes ready. Best default choice.
- StarUML — dedicated UML tool, clean class-diagram support, code export options.
- Visual Paradigm — heavier but full UML suite, free community edition exist.
- Lucidchart — web-based, good UML templates, needs account.
- PlantUML — text-based (not drag-drop), but fast if want version-controllable diagram alongside code.
