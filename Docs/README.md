# Docs/

Guia rápido de onde procurar cada tipo de documento do projeto.

| Pasta | Conteúdo |
|---|---|
| [`Documentos_Entregaveis/`](Documentos_Entregaveis) | Entregáveis oficiais do TCC (artigo, requisitos, UML, diagrama de classes, banco de dados, diagrama elétrico, controle de sessões de orientação). |
| [`Tecnica/`](Tecnica) | Referência técnica interna: arquitetura, protocolo de comunicação com o Arduino, modelo de dados, algoritmo de seleção de torre. |
| [`Projeto/`](Projeto) | Acompanhamento do trabalho em si: contexto, etapas, notas de apoio, log de solicitações, próximas modificações. |
| [`Embasamento_Teorico/`](Embasamento_Teorico) | Material de apoio teórico usado para embasar o artigo (ex.: UML). |

Em caso de dúvida: `Documentos_Entregaveis/` é o que vai para a banca/professor; `Tecnica/` e `Projeto/` são material de trabalho do dia a dia do desenvolvimento.
