# Documentação — RadarTorres

Índice geral da pasta `Docs/`, organizada por finalidade em três subpastas.

| Pasta | Conteúdo |

| [`Tecnica/`](Tecnica/) | Documentação técnica do sistema em si: arquitetura em camadas, protocolo serial PC↔Arduino, modelo de dados (CSV), fundamentação matemática do algoritmo de seleção de torre e referência classe a classe. |
