# Documentação — RadarTorres

Índice geral da pasta `Docs/`, organizada por finalidade em três subpastas.

| Pasta | Conteúdo |
|---|---|
| [`Tecnica/`](Tecnica/) | Documentação técnica do sistema em si: arquitetura em camadas, protocolo serial PC↔Arduino, modelo de dados (CSV), fundamentação matemática do algoritmo de seleção de torre e referência classe a classe. |
| [`Projeto/`](Projeto/) | Documentação do andamento do projeto: contexto/resumo para retomada rápida, registro da Etapa 1 (fundação multiusuário), processo de criação do instalador Windows e o log cronológico de solicitações feitas ao assistente. |
| [`Documentos_Entregaveis/`](Documentos_Entregaveis/) | Documentos acadêmicos entregáveis do TCC — UML e Requisitos do Sistema, com os `.puml` fonte em `Documentos_Entregaveis/Diagramas/` e as versões `.pdf` prontas para entrega. Contém também, em [`Diagramas_e_requisitos/`](Documentos_Entregaveis/Diagramas_e_requisitos/), o levantamento de engenharia de software derivado do código (RF/RNF, decisões arquiteturais, limitações conhecidas, diagramas de classes/pacotes/casos de uso, DER e matriz de rastreabilidade) que fundamenta esses dois documentos. |
