# Projeto/

Acompanhamento do trabalho em si: contexto, etapas, notas de apoio, log de solicitações,
próximas modificações.

- [[CONTEXTO_PROJETO]] — resumo do projeto (stack, arquitetura, estado atual, roadmap), pensado
  para colar como contexto em outra IA.
- [[ETAPA1_FUNDACAO]] — fundação multiusuário (Etapa 1, parte A): arquitetura, tabelas,
  validação, roadmap.
- [[ETAPA2_VISAO_COMPUTACIONAL]] — planejamento do módulo de visão computacional (detecção
  YOLO + mira pan/tilt), ainda não implementado.
- [[IDENTIDADE_VISUAL]] — referência viva da identidade visual (tokens de cor, tipografia,
  ícones).
- [[INSTALADOR]] — processo de criação do instalador Windows (Setup.exe).
- [[LOG_SOLICITACOES]] — histórico cronológico das solicitações feitas ao assistente.
- [[PROXIMAS_MODIFICACOES]] — pendências, decisões e referências rápidas para sessões futuras.
